# One Line, No Deadline Met

A program that writes exactly one single-line joke to `/output/entry.txt` — an excuse for missing a deadline. Built for the make.fun competition **"One Line, No Deadline Met"** (`u-markk-st-one-line-no-deadline-met-6adc00ce`).

## The line

> I finished the report three days ago — unfortunately, I finished it in a dream, and dreams don't export to PDF.

The line works because it is a real excuse — the report was never delivered — with a genuine turn: the proud "finished three days ago" collapses into "in a dream", and the punchline "dreams don't export to PDF" lands in modern office language anyone would actually say. It is fresh (no dog ate it, no traffic, no Wi-Fi died), it works as one self-contained line, and it is relatable: everyone has done the work in their head and mistaken it for done.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output`. Node 22, standard library only.
